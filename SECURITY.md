# Security policy

This repository contains educational examples, including programs that intentionally demonstrate unsafe concurrency patterns such as races, blocking behavior, or deadlocks.

## Reporting issues

If you find a security-sensitive problem that is not simply an intentional teaching example, please open a GitHub issue with enough detail to reproduce it. Do not include private credentials, private infrastructure details, or unrelated personal data.

## Supported scope

The project is not a production library. Security work focuses on keeping examples clear, avoiding accidental unsafe defaults in documentation, and preventing unexpected exposure of private information.
